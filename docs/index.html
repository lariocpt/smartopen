One file. Every door.

A TOML file says which commands can open which files, folders and URLs, and which shortcuts you want a keystroke away. The same file drives every way you reach it.

yazismartopen yazi apply — Enter on any file opens your menu, not a hard-coded viewer.
brootsmartopen broot apply — broot has no per-type opener; now Enter on a file has one.
your shellsmartopen shell zsh — Ctrl+G puts the pick on your prompt line, unexecuted.
a keybindingsmartopen bare is a launcher for the shortcuts that make sense here.

 type to filter · ↑↓ move · 1-9 pick · Alt+key · Enter run · Esc
  • Fuzzy filter with the matched letters highlighted; label hits outrank description hits.
  • 1–9 pick a row; key = "e" binds Alt+E to a command even mid-filter.
  • What you pick often floats up — a one-week half-life, config order as the tiebreak.
  • The right pane shows the truth: the exact command line after quoting, whether its program is installed, what was detected about the file.
  • One match runs immediately. default = true skips the menu; --menu brings it back.
  • Exits with the launched command's exit code.

A launcher that knows where you are.

Shortcuts can depend on the directory, the environment and the tools installed; ask for parameters with a picker fed by a command; remember your last answer; and open in a new terminal window, spelled correctly for whichever terminal you use.

[[shortcut]]
label = "Cargo test"
run   = "cargo test"
group = "rust"
[shortcut.when]
cwd_has = ["Cargo.toml"]   # searched upward, to .git

[[shortcut]]
label = "Checkout branch"
run   = "git checkout {{branch}}"
[shortcut.when]
has = ["git"]              # vanishes where git is missing
[shortcut.param.branch]
choices = "git branch --format='%(refname:short)'"
default = "last"           # your last answer comes first
[[shortcut]]
label   = "Deploy"
run     = "ssh {{host}} 'systemctl restart app'"
confirm = true             # shows the line, asks, default no
[shortcut.when]
env = ["SSH_AUTH_SOCK", "DEPLOY_ENV=prod*"]
[shortcut.param.host]
prompt  = "Which host"
default = "web-1"

[[shortcut]]
label    = "Git UI in a new window"
run      = "gitui"
terminal = true            # $TERMINAL, ghostty, foot, kitty,
cwd      = "."             # alacritty, wezterm, Terminal.app, wt

Already have navi cheats, pet snippets or tldr pages? smartopen shortcuts import navi git.cheat turns them into shortcuts — tags become groups, <arg> becomes a parameter, navi's $ arg: lines become choices.

Matching that sees past the extension.

MIME and shebang

Makefile, Dockerfile, a script with no suffix: the first 8 KiB decide. mime = ["text/*"], shebang = ["python*"] — in yazi's vocabulary.

URLs

smartopen https://github.com/… matches [[url]] by scheme and host glob, with {url}, {scheme}, {host}. C:\… is still a path.

Several at once

smartopen a.csv b.csv offers only the commands every target matches; {paths} is all of them, each quoted.

Project configs

A .smartopen.toml above the working directory or the target — stopping at .git — layers its shortcuts first. A repo can ship its own.

One config, three OSes

platform = "macos" on any command keeps it off the menu elsewhere. Placeholders are quoted for sh or cmd, whichever will run them.

Honest tooling

config doctor says which programs are missing (and exits 0 unless --strict); a misspelt key is an error naming the valid ones; --json on config list, config doctor and tools list.

A first run that sets things up.

smartopen wizard starts with the navigators — yazi and broot, installed first if missing — then walks popular file types one checklist at a time with the terminal tools that open them: ✓ installed, ↓ would be installed, ✗ not installable here. It shows the exact TOML and the exact package-manager commands before anything is written or run. Installs default to no.

smartopen wizard --dry-run     # just the review
smartopen tools list           # the catalogue: what is installed, the one command for the rest

Every install source in the catalogue was checked: a cargo entry means the crate of that name is the tool, a pacman entry means the Arch repos have it. Six popular names on crates.io are unrelated crates; a test refuses them.

Install

curl -fsSL https://lariocpt.github.io/smartopen/install.sh | sh   # Linux (static musl), macOS
cargo install smartopen                                           # crates.io
brew install lariocpt/smartopen/smartopen                         # macOS / Linuxbrew
yay -S smartopen-bin                                              # Arch (AUR)

Every release archive carries smartopen, its alias opn, the README and the license; one SHA256SUMS covers all eight and the installer verifies it before anything becomes executable. Windows builds are on the Releases page.
